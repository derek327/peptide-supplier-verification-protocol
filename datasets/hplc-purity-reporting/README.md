# HPLC Purity Reporting Checklist for Research Peptides v1.0

Which 10 fields must accompany a chromatographic purity claim for a third party to be able to
interpret, reproduce or compare it.

## Contents

| File | Description |
|---|---|
| `hplc-reporting-fields.csv` | The 10 fields with a typical value and the reason each one matters |
| `hplc-reporting-fields.json` | Same content plus comparability rules and common failure modes |

## Method

Fields were derived by asking a single question of each datum normally printed on a purity report:
*if this were missing, could a different laboratory reproduce the number?* Ten fields survived
that test. Four comparability rules state when two purity figures may be compared at all, and four
observed failure modes record how the omission shows up in practice.

## Intended use

- Reviewing a supplier's purity claim before qualification
- Comparing two suppliers' numbers on equal terms
- Specifying what a contract laboratory must report
