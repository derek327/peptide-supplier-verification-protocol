# OEM / Private-Label Peptide Documentation Handover Checklist v1.0

A staged checklist of the documentation a buyer should hold when sourcing peptides under an OEM
or private-label agreement, with the practical failure mode of each missing item.

## Contents

| File | Description |
|---|---|
| `oem-handover-checklist.json` | Full checklist: 19 items with stage, binding status and consequence |
| `oem-handover-checklist.csv` | Same items in flat form |

## Method

Items are grouped by the four stages at which documentation obligations are created:
pre-award, first-article qualification, routine supply, and handover. Each item is marked
`contractual` (should appear as a deliverable in the supply agreement) or `recommended`
(request at qualification). The last column states what goes wrong when the item is absent,
written in buyer-side consequences rather than audit language.

## Intended use

- Negotiation checklist before signing a private-label supply agreement
- Qualification checklist for a new manufacturer
- Handover checklist when a supply relationship ends and product moves elsewhere
