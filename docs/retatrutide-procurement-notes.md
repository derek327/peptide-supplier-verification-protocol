# Retatrutide Research Procurement Notes

Retatrutide is a triple-receptor (GIP / GLP-1 / glucagon) investigational
peptide that has generated sustained interest in metabolic research. These
notes cover the procurement-side specifics a lab buyer should verify — not
the pharmacology, which is the responsibility of the researcher.

## 1. Molecular basics relevant to purchasing

| Item | Note |
|---|---|
| Sequence | 39-amino-acid linear peptide (native sequence, no modifications on standard product) |
| Form | Lyophilized powder, commonly supplied as acetate salt |
| Typical lot size | 1–5 mg research vials; multi-vial bulk for dose-response cohorts |
| Appearance specification | White to off-white lyophilized cake or powder |

## 2. Documentation to request per lot

- **Mass-confirmed identity** — the CoA should state LC-MS (or equivalent)
  confirmation of the intact sequence, not a UV-only identity pass.
- **Purity with method** — HPLC area-% ≥ 95% is a common research baseline;
  the chromatographic method (214 nm, C18, ≥20 min) must be stated.
- **Peptide content** — acetate/counterion weight differs from peptide
  weight; request the stated peptide content % when preparing molar
  concentrations for dosing studies.
- **Endotoxin and bioburden** — confirm whether the lot is stated
  endotoxin-tested if in vivo protocols are planned; many research-grade lots
  are not, and that distinction matters at the desk, not at the bench.

## 3. Common supplier documentation gaps

1. CoA for a different lot than the one shipped (the single most common gap —
   always re-check the vial lot number against the certificate on arrival).
2. Purity reported without the method or chromatogram.
3. "Research use only" disclaimers that are fine — but documentation that
   implies clinical use claims is a compliance red flag for both parties.

## 4. Handling on receipt

- Lyophilized peptide should arrive as a solid cake/powder — a collapsed or
  liquid-looking vial indicates moisture exposure in transit.
- Store per the supplier's stability statement (typically frozen, desiccated,
  protected from light) until reconstitution.
- Reconstitute only in the buffer your protocol specifies; aliquot to avoid
  repeated freeze-thaw cycles of the reconstituted solution.

## 5. Checklist

- [ ] Lot-specific CoA with stated HPLC method and 214–220 nm detection
- [ ] Identity by mass spectrometry
- [ ] Vial lot number matches CoA lot number on arrival
- [ ] Peptide content % stated
- [ ] Stability / storage statement included
- [ ] Endotoxin status known (for in vivo protocols)
